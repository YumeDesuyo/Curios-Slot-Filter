# Changelog

## 1.1.0

- Added compatibility with JEI 15.59.
- Added a `curio` JEI search alias for items with Curios tags or capabilities.
- Changed generic `curio` slot lookup to show both generic and slot-specific Curios items.
- Added runtime diagnostics for mod initialization, JEI connection, slot clicks, and applied filters.

## 1.0.0

- Initial Minecraft 1.20.1 Forge release.
- Added JEI tag filtering and Curios validator result support.
